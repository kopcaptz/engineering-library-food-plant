# Инженерная библиотека пищевого предприятия | ספריית ההנדסה למפעל מזון

Двуязычный (русский / иврит) учебно-практический сайт для инженерной службы пищевого предприятия: пять систем — пар, конденсат, чиллеры, сжатый воздух, обратный осмос. Учебники, интерактивные схемы, диагностика симптомов, тренажёр случаев, калькуляторы, словарь терминов (RU / HE / EN) и сменные журналы.

**Открытая страница:** https://kopcaptz.github.io/engineering-library-food-plant/

Статическая сборка без серверной части и внешних библиотек: достаточно открыть `index.html`. Подробности состава и локального запуска — в `README_DEPLOY.md`.

Редакция v14.1 (учебник и словарь полностью на иврите), расчётное ядро v10.0.
