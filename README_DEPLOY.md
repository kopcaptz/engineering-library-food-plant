# Инженерная библиотека пищевого предприятия | ספריית ההנדסה למפעל מזון (Portable Static Build v15.4 • Core v10.0)

Самодостаточная переносимая статическая сборка двуязычного учебно-практического инженерного сайта (`RU LTR` / `עברית RTL`), готовая к размещению на любом статическом хостинге (GitHub Pages, Cloudflare Pages, Netlify, Nginx, Apache, внутренний интранет-сервер предприятия).

## Состав сборки (редакция v15.4 (2026-10-30), расчётное ядро v10.0)
- `index.html` — главная страница приложения
- `calculators.js` — верифицированное расчётное ядро v10.0 (10 расчётных модулей)
- `calc_ui.js` — двуязычный интерфейс калькуляторов (СИ ⇄ имперские, `$ / ₪`), расчётных карточек и предупреждений
- `app.js` — двуязычный интерфейс главной, поиска по симптомам («Что-то не так»), 5 систем-учебников, интерактивных схем (50 узлов), 6-шагового тренажёра, 30 вопросов самопроверки, полного словаря (84 термина из `GLOSSARY_RU_HE_EN.md` + 7 узких OEM/LOTO терминов) и сменных журналов A4
- `styles/main.css` — адаптивные стили (Desktop / Mobile 360px–412px / Print A4)
- `data/system_{steam,condensate,chillers,air,ro}.js` — двуязычные паспорта систем, 50 узлов схем и таблицы параметров журнала
- `data/guide_{steam,condensate,chillers,air,ro}.js` — полные тексты 5 учебников из `02_guides/01..05.md` (связи показателей, симптомы и причины, границы оператора и LOTO, формулы с примерами, 30 вопросов самопроверки с ответами, сводки источников)
- `data/learning_map.js` — карта входа, маршрута первого знакомства, 8 шагов изучения темы и двух уровней глубины (`Просто / Подробно`)
- `data/experiments.js` — учебные опыты в калькуляторах (`1А, 2, 3Б, 4А, 4Б, 5Б`), физический смысл результата («Что это значит»), ярлыки происхождения полей («измерено / принято / справочно») и строки интерфейса сравнения двух наборов (`А / Б`)
- `data/symptoms.js`, `data/cases_part{1,2}_*.js` — 10 симптомов и 10 пошаговых диагностических случаев
- `data/glossary_and_sources.js` — полный словарь терминов (RU / HE / EN) и реестр 23 первоисточников (`S01–S23`)
- `data/shift_logs.js`, `data/equipment_survey.js`, `data/saved_calculations.js`, `data/steam_table_section.js`, `data/units.js`, `data/i18n_ui.js` — сменные инструменты, таблица пара и переводы интерфейса
- `diagrams/*_{ru,he}.svg` — локализованные русские и ивритские технологические схемы
- `assets/charts/*.svg` — инженерные графики

## Быстрый локальный запуск на любом компьютере
```bash
cd 06_web_project_portable
python3 -m http.server 8090
# Откройте в браузере: http://127.0.0.1:8090/index.html
```

## Политика переносимости и авторских прав
- Сборка **не содержит** абсолютных путей к локальному компьютеру, родительским папкам (`../`), приватных ссылок NotebookLM, архивов или служебных логов.
- Полные защищённые авторским правом PDF-документы производителей (`S01–S23`) не включены в публичный архив; в реестре источников приведены точные библиографические ссылки, проверенные номера страниц и официальные внешние URL правообладателей.
